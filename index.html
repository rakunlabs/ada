Go Web Framework

A net/http compatible mux with batteries-included middleware, built-in auth, and runtime reload.

Getting Started
Guide
GitHub

Simple Mux

Static, parameter, and wildcard routes with backtracking. Path matching is method-agnostic.

Std Compatible

Plain net/http handlers and middlewares work as-is, alongside ada.Context handlers.

Middleware Set

Recover, log, CORS, rate limit, body limit, timeout, telemetry, encoding, and more.

Built-in Auth

OAuth2/OIDC, passkeys, LDAP, magic links, MFA, sessions, and a login UI.

Runtime Reload

Swap, disable, or add middlewares while the server is running, with no restart.

Low Overhead

Zero heap allocations on the request hot path, with benchmarks against Echo and Gin.
